# QA Checklist

## Hierarchy

- [ ] Primary actions are visually dominant with clear accent color
- [ ] Secondary information uses reduced contrast

## Spacing

- [ ] 8-pt grid respected across layout
- [ ] Adequate whitespace around components

## Radii

- [ ] Components use soft radii (12–24)
- [ ] No sharp 90° corners

## Focus

- [ ] Focus indicators visible for keyboard and screen reader navigation
- [ ] Interactive elements have appropriate accessibility roles

## Contrast

- [ ] Text/background contrast meets or exceeds 4.5:1
- [ ] Accent surfaces use tinted backgrounds at 1–3% opacity
- [ ] Supports high-contrast themes

## Motion

- [ ] Press interactions scale to 0.98 and reset smoothly
- [ ] Icon nudges 2px on press
- [ ] Dialogs fade and scale when appearing/disappearing
- [ ] Respects reduced-motion preferences

## Screen Background

- [ ] Every screen is wrapped with `ScreenBackground`
